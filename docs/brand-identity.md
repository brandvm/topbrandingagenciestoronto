# Toronto Brand Review identity

Approved direction: **TOR-C — The Colonnade**.

The selected geometry and outlined playfair-display lettering are retained. Colors match the site's existing palette: symbol #693da3, lettering #2e203c, background #fdfcfe.

The header uses `/wordmark.svg` at desktop sizes and `/brand/logo-compact.svg` at 540px and below. Both show the full publication name, omit the small editorial descriptor for legibility, reserve intrinsic dimensions, and are decorative inside an explicitly named home link. No extra fonts or JavaScript are required. The detailed horizontal, stacked, wordmark, symbol, inverse and monochrome variants are in `public/brand/`; outlined type licenses accompany them.

The favicon uses optically simplified symbol artwork. SVG, ICO (16/32/48), 48px PNG, Apple 180px, Android 192/512px and safe-area maskable 512px versions are provided. The page head and manifest reference the installed set. Organization structured data uses the square 512px logo. `/social.png` also carries the approved identity.

Palette adaptations were explicitly requested alongside production deployment. Article content, review anchors, canonical URLs and staging security remain intact.
